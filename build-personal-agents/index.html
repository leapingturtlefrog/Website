Build Personal Agents


Godel is a Gödel machine-inspired personal agent that starts with only bash and writes new abilities into itself. A wall it can't touch checks each new version (tests, mutation testing, evals, screenshot review) before it goes live, and can roll any version back in one click. It has its own email, browser, and credit card.


Tech: Neon (AI Gateway, Postgres, branches and snapshots, Auth), Fly.io Sprites, Kernel, Exa, AgentMail, Mercury, assistant-ui, Next.js, Hono, Playwright, Stryker.
